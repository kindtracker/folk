# folk

Folk is an old Roblox-style web client designed to run Vortex on every device.
It does not connect to the official servers yet.

## Roadmap
- [ ] Have community servers
- [ ] Have custom maps published by community

## Goals
- [ ] Connect to official servers

## Quickstart (Linux)
### Requirements
- Linux
- Node.js
- NPM

### To run Folk
```
$ git clone https://github.com/kindtracker/folk
$ cd folk_pub
$ npm install
$ npm run server
```
Open http://127.0.0.1:6969/?game_id=1&webgpu=true
